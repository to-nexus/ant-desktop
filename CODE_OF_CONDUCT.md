# Code of Conduct

Ant Desktop is part of the [Ant](https://github.com/to-nexus/ant) project and is
governed by the same Code of Conduct — the
[Contributor Covenant 2.1](https://github.com/to-nexus/ant/blob/main/CODE_OF_CONDUCT.md).

It is kept in one place on purpose: two copies of the same policy drift, and a
drifted code of conduct is worse than a single linked one.

**Reporting.** Report unacceptable behaviour to `probe@to.nexus`. Reports are
handled confidentially. Enforcement follows the guidelines in the canonical
document linked above.
